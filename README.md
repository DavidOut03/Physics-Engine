# Physics Engine

Since the comming of AI i was getting bored while coding. I wanted to get the spark back. That why i started this projet i wanted to do for a long time. I also wanted to do more with the math i learned at the University.

Project:
Build a 2D physics engine build from scratch, with HTML canvas.

## Rules I hold myself to

- **No  Generative AI/coding agents** Coding this myself, while only using a assigment generated by AI without the answers and chrome.

- **No physics or math libraries.** Only TypeScript, the canvas and Vite. My own
  `Vector2D`, my own integrators.

- **Allowed sources:** MDN, the TypeScript handbook, textbooks, Khan Academy.

## Stack

| | |
|---|---|
| Language | TypeScript 5.8 |
| Bundler / dev server | Vite 6 |
| Rendering | HTML5 canvas 2D context |
| Tests | plain `console.assert` in the browser console |

## Getting started

```bash
npm install
npm run dev
```

Then open the URL Vite prints. Vite compiles the TypeScript and reloads the page
on save.

```bash
npm run build     # type-check with tsc, then build to dist/
npm run preview   # serve the production build
```

## Controls

| Key | What it does |
|---|---|
| `P` | Pause / resume |
| `N` | Advance exactly one fixed step (while paused) |
| `D` | Toggle the debug overlay (paused state, FPS, playback speed) |
| `S` | Toggle slow motion (1× ↔ 0.2×) |
| `V` | Toggle velocity arrows on every body |

## Roadmap

| | Part | Status |
|---|---|---|
| 0 | Setup & canvas — pixels, the 2D context, drawing a circle | ✅ |

| 5 | Walls & bouncing — detection by radius, restitution, resting bodies, friction | ⬜ |

| 7 | Energy & integrators — kinetic and potential energy, explicit Euler vs. semi-implicit vs. Verlet | ⬜ |
| 8 | Springs & ropes — Hooke's law, damping, fixed points, breaking springs | ⬜ |
| 9 | Sandbox — mouse tools, grabbing and throwing, settings, save/load as JSON | ⬜ |
| 10 | Spring slingshot — a game whose slingshot, ropes and platforms are all springs | ⬜ |
| 11 | Bonus — spatial grid for 1000+ balls, planets, double pendulums, ramps, boxes | ⬜ |
